## Project Purpose

This project was created to demonstrate practical familiarity with OSINT tools commonly referenced in cybersecurity.

OSINT, or Open Source Intelligence, is the process of collecting and analyzing publicly available information to support decision-making. In cybersecurity, OSINT can help analysts investigate suspicious domains, IP addresses, URLs, exposed services, certificates, threat actors, and indicators of compromise.

## Cybersecurity Use Case

In a SOC or security operations environment, OSINT can support:

- Alert triage
- Phishing investigation
- IOC enrichment
- Threat intelligence research
- Attack surface awareness
- Incident response scoping

## Investigation Scope

This project focuses on safe, passive, and publicly available research methods. No exploitation, unauthorized scanning, credential access, or intrusive activity will be performed.

## Planned Workflow

1. Select a domain or indicator for investigation
2. Review domain registration and DNS information
3. Identify related subdomains and certificates
4. Enrich IP address and URL reputation data
5. Review threat intelligence sources
6. Document findings and recommendations
